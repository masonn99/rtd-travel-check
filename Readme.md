# RTD Travel Check

**Visa requirements for US Refugee Travel Document (I-131 / I-571) holders — built by the community, for the community.**

Live site: [rtd-travel-check.vercel.app](https://rtd-travel-check.vercel.app)

RTD holders face a unique challenge: standard passport-based visa guides don't apply to them. This project fills that gap with community-sourced travel data, real experiences shared by fellow RTD holders, and an AI assistant that can answer travel questions using that community knowledge.

---

## Features

- **Visa Map** — Interactive world map showing visa requirements per country
- **Country Directory** — Searchable table with visa type, embassy contacts, and notes
- **Community Stories** — Real experiences shared by RTD holders, submitted via Telegram
- **AI Assistant** — Chat interface powered by Groq + Gemini, trained on community data
- **Telegram Pipeline** — Messages in the community group are automatically extracted and submitted for admin review

## Getting Started

### Prerequisites

- Node.js 18+
- A [Neon](https://neon.tech) account (free tier works)
- Optional: Telegram bot token (for the community ingestion pipeline)
- Optional: Groq and/or Gemini API keys (for AI chat)

### 1. Clone and install

```bash
git clone https://github.com/masonn99/rtd-travel-check.git
cd rtd-travel-check
npm install
```

### 2. Configure environment variables

Copy `.env.example` to `.env.local` and fill in your values:

```bash
cp .env.example .env.local
```

| Variable | Required | Description |
|---|---|---|
| `DATABASE_URL` | Yes | Neon PostgreSQL connection string |
| `TELEGRAM_BOT_TOKEN` | Optional | From [@BotFather](https://t.me/BotFather) — enables story ingestion |
| `ADMIN_TELEGRAM_ID` | Optional | Your personal Telegram ID — who can approve/reject stories |
| `TELEGRAM_GROUP_ID` | Optional | Restrict ingestion to one group (recommended) |
| `GEMINI_API_KEY` | Optional | From [aistudio.google.com](https://aistudio.google.com/app/apikey) — primary AI extractor |
| `GROQ_API_KEY` | Optional | From [console.groq.com](https://console.groq.com/keys) — AI chat + fallback extractor |

The app works without the optional keys — the AI chat and Telegram pipeline just won't be active.

### 3. Set up the database

```bash
npm run migrate
```

This creates the required tables (safe to re-run — uses `IF NOT EXISTS`).

### 4. Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## How to Contribute

Contributions of all kinds are welcome — visa data corrections, new country entries, bug fixes, UI improvements, and more.

### Adding or updating visa data

Visa requirements live in [`data.json`](./data.json) at the root of the project. Each entry looks like:

```json
{
  "country": "Japan",
  "countryCode": "JP",
  "visaRequirement": "Visa required",
  "notes": "Single-entry tourist visa available at embassy"
}
```

**`visaRequirement` values:**
- `"Visa not required"` — visa-free entry
- `"E-Visa"` — electronic visa available online
- `"Visa required"` — must apply at embassy/consulate
- `"Does not recognize RTD"` — country does not accept RTD as travel document

To add or update a country, edit `data.json` and open a pull request. Please include a source (embassy website, official policy page, or community report) in your PR description.

### Sharing a travel experience

The easiest way is to join the [Telegram group](https://t.me/+hgENDIRxoTs0NGQx) and share your experience there — the bot automatically picks it up for review.

You can also submit directly via the Community tab on the website.

### Reporting incorrect data

Open a [GitHub issue](https://github.com/masonn99/rtd-travel-check/issues) with:
- The country name
- What the current data says
- What it should say
- A link to a source if possible

### Code contributions

1. Fork the repo and create a branch: `git checkout -b your-feature`
2. Make your changes
3. Run `npm run lint` to check for issues
4. Open a pull request with a clear description of what changed and why

There's no strict style guide — just match the existing patterns and keep PRs focused.

## Telegram Bot Setup

If you want to run the community ingestion pipeline locally:

1. Create a bot via [@BotFather](https://t.me/BotFather) and get the token
2. Add the bot to your Telegram group and disable privacy mode (BotFather → Bot Settings → Group Privacy → Turn Off)
3. Remove and re-add the bot to the group after disabling privacy mode (required for the setting to take effect)
4. Set the webhook to your local tunnel URL:
   ```
   https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://your-tunnel.ngrok.io/api/telegram
   ```
5. Set `TELEGRAM_GROUP_ID` to restrict ingestion to your group only

When someone posts in the group, the bot uses NLP + AI (Gemini/Groq) to extract country, visa type, and experience description. Extracted stories go to `pending_review` status and the admin receives an approve/reject button in a private Telegram message.

## Deployment

The project is designed to deploy to Vercel with zero config:

1. Push to GitHub
2. Import the repo on [vercel.com](https://vercel.com)
3. Add environment variables in the Vercel dashboard
4. Deploy

The `DATABASE_URL` must point to a Neon database. Run `npm run migrate` once after setting up the database (you can do this locally with the same `DATABASE_URL`).
